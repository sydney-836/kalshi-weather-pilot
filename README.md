# Kalshi Weather Markets — Live Pilot Results (Jun 21 – Aug 3, 2026)

Trade-level results from a 44-day live research pilot trading daily
high-temperature range contracts on Kalshi with a small real-money account.(Ten dollars)

**Strategy tested:** buy NO on a temperature bucket when the NWS forecast high
clears the bucket's upper bound by 0–2°F.

**Headline result:** the strategy as-traded lost (40.9% win rate vs 51.8%
breakeven across 115 held-to-settlement markets). Split by entry price, the
picture inverts: entries at NO ≤ 50¢ (market disagreeing with the forecast) won
65.5% vs a 38.6% breakeven (+27pp, n=58); entries at NO > 50¢ (market already
agreeing) won 18.2% vs 58.8% needed and account for the entire loss.

All outcomes verified against the exchange's actual settlements, not
reconstructed from weather data. One caveat learned the hard way: NWS
settlement stations must be read from each market's rules. Austin and Houston
do not settle at the airports you would guess.

This is preliminary, post-hoc evidence from one summer. A pre-registered
100-day forward test of the NO ≤ 50¢ rule (kill criteria locked in advance)
is running next. Results will be published either way:)
